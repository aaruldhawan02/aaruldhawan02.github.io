# Portfolio Website Design Style Guide

## Design Philosophy

### Color Palette
- **Primary**: Deep charcoal (#1a1a1a) and warm off-white (#f8f8f6) for high contrast readability
- **Accent**: Muted amber (#d4a574) for highlights and interactive elements
- **Secondary**: Soft sage green (#8fa68e) for success states and secondary actions
- **Neutral**: Medium gray (#6b7280) for supporting text and subtle elements
- **Background**: Consistent dark theme (#0d0d0d) with subtle texture

### Typography
- **Display Font**: "Tiempos Headline" - Bold serif for headings and hero text
- **Body Font**: "Suisse Int'l" - Clean sans-serif for readability and modern feel
- **Code Font**: "JetBrains Mono" - For technical content and code snippets
- **Hierarchy**: Large display headings, medium section titles, small body text for information density

### Visual Language
- **Minimalist Precision**: Clean lines, generous whitespace, surgical focus on content
- **Technical Elegance**: Subtle references to distributed systems, network topology, and code architecture
- **Professional Authority**: Sophisticated color choices that convey expertise without flashiness
- **Information Density**: Compact layouts that showcase extensive experience efficiently

## Visual Effects & Animation

### Used Libraries
- **Anime.js**: Smooth micro-interactions and page transitions
- **ECharts.js**: Interactive skills visualization and data representation
- **Shader-park**: Subtle background effects and ambient visuals
- **Splide.js**: Project carousel and image galleries
- **p5.js**: Creative coding elements for hero section

### Effect Implementation

#### Header/Hero Effects
- **Animated Network Topology**: Subtle background visualization of connected nodes representing distributed systems
- **Typewriter Animation**: Hero text appears with typing effect using Typed.js
- **Particle System**: Gentle floating particles suggesting data flow and connectivity
- **Gradient Flow**: Soft, slow-moving gradients in brand colors as background texture

#### Interactive Elements
- **Timeline Animation**: Work experience nodes expand with smooth easing when clicked
- **Project Cards**: 3D tilt effect on hover with depth shadows
- **Skills Visualization**: Animated radar chart showing proficiency levels with staggered reveals
- **Form Interactions**: Floating labels with smooth transitions and validation states

#### Scroll Motion
- **Subtle Reveals**: Content fades in with 16px upward motion as it enters viewport
- **Parallax Layers**: Background elements move at 0.5x scroll speed for depth
- **Progress Indicators**: Subtle scroll progress bar in brand accent color
- **Section Transitions**: Gentle fade between sections with 200ms timing

#### Hover Effects
- **Button Morphing**: Color transitions with subtle scale (1.02x) and shadow expansion
- **Image Overlays**: Gradient masks reveal on hover with project information
- **Navigation States**: Underline animations with brand accent color
- **Card Elevation**: Lift effect with increased shadow and subtle border glow

### Styling Approach
- **Grid-Based Layout**: Consistent 8px grid system for precise alignment
- **Card-Based Components**: Elevated surfaces with subtle borders and shadows
- **Responsive Design**: Mobile-first approach with breakpoints at 768px and 1024px
- **Dark Theme Optimization**: High contrast ratios (4.5:1+) for accessibility
- **Consistent Spacing**: 16px, 24px, 32px, 48px spacing scale throughout

### Background Treatment
- **Consistent Base**: Dark background (#0d0d0d) maintained across all sections
- **Subtle Texture**: Very light noise pattern (2% opacity) for visual interest
- **Decorative Elements**: Geometric shapes and network diagrams as background elements
- **Section Differentiation**: Subtle border lines and spacing rather than background color changes
